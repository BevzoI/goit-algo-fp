# goit-algo-fp
Завдання 7: Метод Монте-Карло для кидання двох кубиків

Опис

У цьому завданні було реалізовано програму, яка імітує процес кидання двох ігрових кубиків з використанням методу Монте-Карло. Метою є обчислення ймовірностей отримання кожної можливої суми (від 2 до 12) і порівняння результатів з аналітичними (теоретичними) значеннями.

Реалізація

 Використано Python для симуляції 100 000 кидків двох кубиків.
 Підраховано кількість випадків для кожної суми.
 Обчислено ймовірності шляхом ділення кількості випадків на загальну кількість кидків.
 Створено графік для візуального порівняння емпіричних (Монте-Карло) і аналітичних ймовірностей.
 Побудовано таблицю з числовим порівнянням результатів.
 Графік ймовірностей автоматично зберігається у файл `dice_simulation.png` у поточній папці.

Висновок

Отримані за допомогою методу Монте-Карло результати дуже близькі до аналітичних значень. Максимальне відхилення складає близько 0.0014, що свідчить про високу точність симуляції при великій кількості експериментів.

Метод Монте-Карло є ефективним інструментом для статистичного моделювання та оцінки ймовірностей у випадкових процесах.
